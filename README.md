# CloudBlitz Pages

A comprehensive training platform hub for CloudBlitz courses.

## 🏠 Home Page

The home page serves as the main navigation hub, providing access to different training platforms:

### Navigation Options

- **EMI Platform** - Expert in Data Science and Analytics with AI
- **TL Platform** - Cloud DevOps Engineering Course with AI

### Features

- **Modern UI/UX** - Clean, responsive design with smooth animations
- **Accessibility** - Keyboard navigation support and proper ARIA labels
- **Loading States** - Visual feedback during navigation
- **Error Handling** - Graceful error recovery
- **Analytics Ready** - Built-in tracking capabilities

## 📁 Directory Structure

```
/
├── index.html          # Home page
├── styles.css          # Home page styles
├── app.js             # Home page functionality
├── ms-logo.png        # Logo image
├── emi/               # EMI platform files
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── tl/                # TL platform files
    ├── index.html
    ├── styles.css
    ├── app.js

    └── README.md
```

## 🚀 Getting Started

1. **Access the Home Page**: Navigate to the root directory
2. **Choose Platform**: Click on either EMI or TL button
3. **Start Training**: You'll be redirected to the respective platform

## 🎨 Design Features

- **Gradient Background** - Modern gradient design
- **Card-based Layout** - Clean, organized interface
- **Hover Effects** - Interactive elements with smooth transitions
- **Responsive Design** - Works on all device sizes
- **Loading Animations** - Smooth page transitions

## ⌨️ Keyboard Shortcuts

- **1** - Navigate to EMI platform
- **2** - Navigate to TL platform
- **Enter** - Activate focused button

## 🔧 Technical Details

- **Pure HTML/CSS/JavaScript** - No external frameworks
- **Modern CSS** - Flexbox, Grid, and CSS animations
- **ES6+ JavaScript** - Modern JavaScript features
- **Accessibility** - WCAG compliant design
- **Performance** - Optimized for fast loading
